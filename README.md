# Darbak Jordan · دربك الأردن
### Pure HTML, CSS & JavaScript Edition (Ready for VS Code)

This folder contains the complete **Darbak Jordan** website built exclusively using pure **HTML5, CSS3, and Vanilla JavaScript**.

There are **zero external dependencies, zero build steps, and zero npm packages required**.

---

### Folder Structure
```text
vanilla/
├── index.html       # Complete HTML with Home, What We Do, Explore, JMap, Dream Trip, etc.
├── style.css        # Clean responsive CSS styling, Google Fonts, and animations
├── app.js           # Vanilla JavaScript for navigation, map pins, calendar, modals & search
├── assets/          # High-resolution images (Petra, Wadi Rum, Dead Sea, Mansaf, Jerash, etc.)
└── README.md        # Instructions
```

---

### How to Open and Run in VS Code:

#### Method 1: Using VS Code "Live Server" (Recommended)
1. Open **VS Code**.
2. Go to **File → Open Folder...** and select this `vanilla` folder.
3. If you haven't installed it yet, install the popular **Live Server** extension (by Ritwick Dey) from the VS Code Extensions tab (`Ctrl+Shift+X` or `Cmd+Shift+X`).
4. Right-click `index.html` in the file tree and click **"Open with Live Server"**.
5. Your browser will automatically open at `http://127.0.0.1:5500/index.html`.

#### Method 2: Direct Browser Opening (No Server Needed)
- Simply open the `vanilla` folder in your file explorer (Finder on macOS or File Explorer on Windows).
- Double-click `index.html` to open it in Chrome, Safari, Edge, or Firefox!

### Features Included:
- **Navigation Bar**: Jordanian 7-pointed star insignia, links, language switcher (EN / AR), saved trip counter, login button.
- **Home Page**: Warm parchment aesthetic, Discover Jordan Your Way hero, stats ribbon, Curated Masterpieces (The Wonders of Jordan), and traveler testimonials.
- **What We Do**: Six Pillars of Perfect Travels and Three Simple Milestones.
- **Explore Jordan**: Search bar and categories (*Hidden Gems*, *History & Culture*, *Nature*, *Adventure*, *Relaxation*, etc.).
- **JMap Interactive Map**: Custom map canvas with icons for ancient ruins, mountains, nature, and food, interactive pin cards with seasonal advice and visit tips.
- **Design My Dream Trip**: Duration selection (3, 5, 7, 10, 14 days), interests, traveler type, must-visit destinations, and 5-Day Jordan Odyssey timeline.
- **About Jordan**: Historic cities, cultural timeline, traditional food (Mansaf, Knafeh, Maqluba), and UNESCO sanctuaries.
- **Live Like a Local**: 4+ immersive experiences (Mansaf cooking, Tatreez embroidery, Tahdeeb Shmagh, Bedouin coffee) with instant booking modal.
- **Tourists Stories**: Real traveler archives with interactive story submission form.
- **Saved Trip Calendar**: Interactive monthly calendar with scheduled stops and print/export feature.
